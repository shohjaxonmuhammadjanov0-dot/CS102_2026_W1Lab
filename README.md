# C++ Practice

This repo contains C++ practice programs from my first-year Computer Programming course at New Uzbekistan University.

Start with [`recursions.cpp`](recursions.cpp), which counts how often a digit appears using recursion.

The `cpp-practice/` folder contains additional recursion exercises:
- `cpp-practice/2.cpp` uses recursion for Fibonacci.
- `cpp-practice/3.cpp` counts set bits recursively.
- `cpp-practice/4.cpp` counts the bit flips between two numbers.
- `cpp-practice/5.cpp` checks whether a number is a power of four.
- `cpp-practice/6.cpp` simulates a child passing a ball.
- `cpp-practice/7.cpp` computes powers recursively.
